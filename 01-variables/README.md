# C# Variables

 - Variables are containers for storing data values


# Types 

- int : whole numbers whitout decimals such as 12 or -12 

- double : floating point number with decimals such as 12.99 or -12.99 

- char : stores charcaters such as 'a' or 'A' char varibles uses single quotes '_'

- string : stores text such as 'Hello Nassim'

- bool stores values with the two states true or false
